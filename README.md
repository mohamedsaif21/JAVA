# Java Study Guide

A structured Java learning repository containing beginner-friendly lessons, examples, exercises, problem-solving practice, and preparation material for coding interviews and LeetCode.

## About This Repository

This repository is designed as a practical Java study guide. It starts with the fundamentals of Java programming and gradually moves toward problem solving, object-oriented programming, collections, algorithmic thinking, and interview preparation.

The code is organized into topic-based directories so learners can study one concept at a time, run the examples, modify the code, and practice solving related problems.

## Java Learning Roadmap

Recommended learning path:

1. Learn Java syntax, variables, data types, input, and operators.
2. Practice decision-making and looping statements.
3. Solve pattern and basic programming exercises.
4. Learn methods, arrays, and strings.
5. Understand object-oriented programming.
6. Study collections and common data structures.
7. Learn time and space complexity.
8. Solve practice problems and LeetCode questions.
9. Review coding interview topics and improve problem-solving speed.

## 22. How to Run the Programs

You can run the Java programs using an IDE such as IntelliJ IDEA, Eclipse, or Visual Studio Code, or by using the command line.

### Compile a Java File

```bash
javac FileName.java
```

### Run the Compiled Program

```bash
java FileName
```

Make sure the public class name matches the Java file name. For example, a public class named `Main` should be saved in `Main.java`.
